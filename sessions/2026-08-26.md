## Uncountable `practice` pluralized

- **Wrote:** This project is for English practices.
- **Better:** This project is for English practice. / This project is for
  practicing English.
- **Why:** `practice` meaning "repeated exercise to improve a skill" is
  uncountable and takes no plural. The plural `practices` exists but means
  "customary ways of doing things" — *best practices*, *hiring practices* — which
  is a different word in effect.
